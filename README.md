# Lead finder: נותני שירות בשטח

סורק עסקי שירות בשטח באזור ניצן (אשדוד, אשקלון, ראשון לציון, יבנה, גן יבנה, קריית מלאכי, ניצן),
מחפש סימנים לבעיות תיאום ותהליכים ידניים, ומדרג אותם.

## איך זה רץ
- GitHub Actions (`.github/workflows/scan.yml`) רץ כל יום ומבצע עד 30 חיפושים ב-Google Places,
  כדי להישאר בתוך המכסה החינמית. כל עיר+ענף נשמרים ב-`data/places/` ומחופשים מחדש רק אחרי 30 יום.
- צריך סוד ב-GitHub בשם `GOOGLE_PLACES_API_KEY`.
- הרצה ידנית: `python -m lead_finder.run`

## מה יוצא
- `output/leads.csv`: כל העסקים, ממוינים לפי ציון (נפתח באקסל / Google Sheets).
- `output/summary.md`: השוואה בין הענפים.

הציון הוא סינון ראשוני בלבד. ללידים המובילים נעשה ניתוח עמוק (מודעות דרושים, ביקורות מלאות) לפני שיחה.

## הגדרות
ערים, ענפים ומגבלות: `lead_finder/config.py`. סימני הכאב והניקוד: `lead_finder/signals.py`.
